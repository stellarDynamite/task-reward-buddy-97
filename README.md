# 🎮 Life Gamification

> **Turn your daily grind into a game.**

Life Gamification is a productivity app that makes getting things done a little more fun.

Complete tasks, build habits, earn XP, level up, unlock rewards, maintain streaks — and get a little celebration every time you make progress. 🎉

Because sometimes a boring checklist just needs **more dopamine.**

---

## ✨ Why This Isn't Just Another Todo App

Most todo apps tell you what you need to do.

**Life Gamification gives you a reason to actually do it.**

### ⭐ XP & Levels

Every completed task and habit earns you **XP**.

Fill your XP bar → **Level up.**

Bad habits can cost you XP too, so your choices actually matter.

Your level won't randomly disappear because you had one bad day, though. You've earned it.

### 🎁 Rewards

Your XP isn't just a number.

Create your own rewards and spend your XP on things you actually want:

- 🎬 Watch a movie
- 🍕 Order takeout
- 🎮 Play games
- ☕ Get your favorite coffee

Redeeming a reward reduces your XP, but **your level stays yours.**

You earned it.

### 🔥 Streaks

Consistency deserves to be celebrated.

A calendar tracks the days you've earned XP, so you can see your progress building over time.

**Keep the streak alive.**

### 🐣 Motivation Buddy

Reach **Level 3** and unlock your little motivation buddy.

Your buddy gives you fresh motivational messages as you progress — with non-repeating lines, because nobody wants to hear *"You got this!"* 47 times.

### 🎉 Progress Celebrations

Because checking off a task should feel at least a little satisfying.

| Progress | Celebration |
| --- | --- |
| Complete 1 task | 🎊 Confetti |
| Complete 3 tasks | 🎈 Balloons |
| Complete 4 tasks | 🌈 Rainbow |

Is it necessary?

No.

Is it fun?

**Absolutely.**

### 🛡️ Daily Limits

You can earn a maximum of **400 XP and 3 levels per day**.

This keeps progression balanced and prevents the classic:

> *"It's 11:58 PM and suddenly I need to complete my entire life."*

### ☁️ Cloud Sync

Sign in with **Google or email** and your progress follows you across devices.

Don't want an account?

No problem.

**Local mode works too.**

### 🌙 Dark & Light Mode

Because staring at a bright white screen at 2 AM is basically a side quest nobody asked for.

## 🚀 Run Locally

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

If you don't have them, you can install Node.js using [nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

### 1. Clone the repository

```bash
git clone <YOUR_GIT_URL>
```

### 2. Navigate to the project

```bash
cd <YOUR_PROJECT_NAME>
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The app will start with hot reloading and an instant local preview.
